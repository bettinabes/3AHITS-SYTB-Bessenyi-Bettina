# Theorie


## grep

grep durchsucht Dateien oder Texte nach bestimmte Wörter oder Muster


Einfacher Textvergleich

```
grep "Werkstatt" klassenkassa.csv
```

grep sucht nach allen Zeilen, die das Wort Werkstatt enthalten.


## Regular Expressions

Alles mit W anzeigen

```
grep 'W.*' klassenkassa.csv
```

- W - beginnt mit W
- . - ein beliebiges Zeichen
- \* - beliebig oft




W gefolgt von einem Zeichen


```
grep 'W.' klassenkassa.csv
```

W. sucht nach W plus einem beliebigen Zeichen.


Zahlen zwischen 10 und 19 suchen

```
grep '1[0-9]\.' klassenkassa.csv
```

- 1 - beginnt mit 1
- [0-9] - beliebige Ziffer
- \. - Punkt

```
grep -o '1[0-9]\.' klassenkassa.csv
```

-o gibt nur den gefundenen Ausdruck aus, nicht die ganze Zeile


Datum suchen

```
grep '1[0-9]\.[0-9][0-9]\.' klassenkassa.csv
```

Findet Datumsangaben mit Tagen 10–19


## sed

sed wird verwendet um Texte zu ersetzen oder zu bearbeiten


Wort ersetzen

```
echo "1234ccbbaa1234" | sed "s/ccbbaa/XZY/"
```

- s - substitute
- ccbbaa - Text zu suchen
- XZY - Ersatztext

Ergebnis:
```
1234XZY1234
```

Zwei beliebige Zeichen ersetzen

```
echo "1234ccxxaa1234" | sed "s/cc..aa/XZY/"
```

- . - ein beliebiges Zeichen
- .. - zwei beliebige Zeichen



a oder b ersetzen

```
echo 'jhagfh' | sed 's/[ab]/XYZ/'
```

- [ab] → a oder b

Ergebnis:
```
jhXYZgfh
```


Beliebig viele Zeichen

```
echo 'jhagfah' | sed 's/[ab]*/XYZ/'
```

- \* - 0 oder mehr Wiederholungen



Erweiterte Regex

```
echo 'jhabbbbaabgfah' | sed -E 's/[ab]+/XYZ/'
```

- -E - Extended Regex aktivieren
- \+ - mindestens ein Zeichen



Versionsnummer ersetzen

```
echo 'Version V12.51 / March 2026' | sed 's/V[0-9]*\.[0-9]*/---/'
```

Regex:

- V
- [0-9]*
- \.
- [0-9]*

Erkennt: V12.51

Ergebnis: Version --- / March 2026


Gefundenen Ausdruck wiederverwenden

```
echo 'Version V12.51 / March 2026' | sed 's/V[0-9]*\.[0-9]*/(&)/'
```

- & = gefundener Ausdruck

Ergebnis:

```
Version (V12.51) / March 2026
```



Nicht-Kleinbuchstaben ersetzen

```
echo 'jlkjsfAjkj' | sed 's/[^a-z]/_/'
```

- ^ innerhalb [] = NICHT
- [^a-z] = alles außer Kleinbuchstaben

Ergebnis: 
```
jlkjsf_jkj
```
