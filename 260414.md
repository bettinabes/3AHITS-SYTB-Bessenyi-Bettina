Vergleiche die Ausgaben von

ls

ls | cat

echo "$(ls)"


```
┌──(kali㉿kali)-[~/SYTB/test]
└─$ ls
dir1  test1.txt  test2.txt  test4.txt
                                                                             
┌──(kali㉿kali)-[~/SYTB/test]
└─$ ls | cat
dir1
test1.txt
test2.txt
test4.txt
                                                                             
┌──(kali㉿kali)-[~/SYTB/test]
└─$ echo "$(ls)"                 
dir1
test1.txt
test2.txt
test4.txt
```

Unterschied der Ausgaben

Die drei Befehle liefern unterschiedliche Darstellungen der gleichen Daten:

ls gibt die Inhalte eines Verzeichnisses standardmäßig spaltenweise aus, abhängig von der Terminalbreite.
ls | cat gibt die Ausgabe zeilenweise aus, da die Pipe (|) die Ausgabe von ls an cat weiterleitet, welches jede Zeile einzeln ausgibt.
echo "$(ls)" nutzt Command Substitution und übernimmt die Ausgabe von ls als String. Dabei bleiben die Zeilenumbrüche erhalten, weshalb die Ausgabe ebenfalls untereinander erscheint.

Logik dahinter:
Pipes (|) leiten die Ausgabe eines Befehls direkt an einen anderen weiter, während Command Substitution $(...) die Ausgabe eines Befehls in einen String umwandelt und innerhalb eines anderen Befehls verwendet.
